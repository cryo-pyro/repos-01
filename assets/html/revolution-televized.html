The Architecture Rule

Why This Holds

Most AI medical systems blur the line between inference and state. Ours doesn't. Claude returns a pure JSON gradient vector plus a reasoning trace. JavaScript reads it. JavaScript writes it. Claude never touches the twin directly.

This means the state is auditable, versioned, and exportable at every step. It means a clinician or patient can pause, inspect, and resume. It means the system is a ledger, not a conversation.

That distinction — ledger vs. chat — is everything. Ukubona Pentad v2.0 formalises it as medicine mapped to gradient descent: θ → L → ∇L → −η∇L → θ′ → repeat.
