All three non-Gemini AI voices converge on a set of corrections that must be preserved. The document would be dishonest without them.

Correction 1 — The Pentad Is Not a Rank Ladder

The sequence Tensor → Vector → Matrix → Eigenvector → Scalar does not describe a progression of tensor ranks. It describes a computational pipeline for decision-making under uncertainty. The distinction is critical: rank describes structure; the pentad describes compression.

Source: OpenAI Section I, xAI Section II, Anthropic Section I

Correction 2 — The Leakage Model Is Under-Specified

(procured − consumed) × price captures inventory mismatch only. Real leakage includes price inflation, ghost procurement, timing delays, and substitution fraud. These require additional axes — vendor, approver, location — expanding the tensor from rank-3 to rank-5 or rank-6. At that point, eigenvectors start pointing at people and networks, not just categories.

Source: OpenAI Section IX, xAI Section V

Correction 3 — The Sovereign Slicing Is Architecture, Not Implementation

The federated gradient protocol (local computation, directional vector sharing) is correctly described. It is not yet implemented in the setup.sh code. The next 20 lines of PySyft or Flower would make the "Ukubona Constitution" enforceable in law rather than in prose.

Source: xAI Section V, Anthropic Section I

Correction 4 — The Geo Map Is Still Synthetic

The synthLeakage(site, idx) function generates leakage from a deterministic mathematical formula, not from real site data. The system is currently demonstrating structure it was designed to find. Connecting /analytics/eigen to the map coloring would close this gap. Until then, the map is a demonstration, not a diagnostic instrument.

Source: OpenAI Sections III–V, Anthropic Section I
